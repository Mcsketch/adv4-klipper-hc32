# Roadmap

Brainstorm, 2026-11-03. Order inside each area is the suggested build order.
"Have" lists what the printer already does, so nothing gets built twice.

## Where it stands

Have: Klipper on the MCU, Moonraker 0.11 (job queue, history, object
processing on), Mainsail, `exclude_object`, `pause_resume`, `respond`,
`firmware_retraction`, the panel with Print / Preheat / Filament / Tools
menus, `HOME_XYZ`, `PRINT_START` / `PRINT_END`, `LOAD_FILAMENT` /
`UNLOAD_FILAMENT`.

Missing that matters: no thumbnail or ETA on the panel during a job, no
camera, no light control, no `M600`, `[bed_mesh]` present but no probe,
no recorded slicer choice, no pressure advance or input shaper calibration.

Known limits that cap everything below:

| Limit | Value | Effect |
|---|---|---|
| Hot end flow | slips near 4.8 mm³/s | 0.2 x 0.45 mm lines top out near 53 mm/s |
| Speed cap (Caleb) | 60 mm/s incl. travel | until lifted |
| Z | 5 mm/s (10 stalls up), whines | known issue, HARDWARE.md |
| SoC | V3S, ~55 MB RAM, busybox | printer-side code must be tiny C |

## 1. Job info on the panel (G-code processing)

Goal: send a job, the panel shows the model, an honest finish time and the
numbers that matter, from the first layer to the last.

| ID | Item | Approach | Status |
|---|---|---|---|
| J1 | Slicer metadata reaches Moonraker | Slicer header must match Moonraker's PrusaSlicer pattern (`; generated by X on DATE at TIME`, Orca and its forks do). Check one real sliced file: `slicer`, `estimated_time`, `thumbnails` in `/server/files/metadata`. The test files on the host are hand-made and report `Unknown`. | ready |
| J2 | Accurate time | Run [klipper_estimator](https://github.com/Annex-Engineering/klipper_estimator) as the slicer's post-processing step. It simulates Klipper's own motion planner with this printer's limits (read from Moonraker) and rewrites the estimate and `M73` progress. Usually within a few percent; slicer estimates on Klipper are often 10-30 % off. | ready |
| J3 | Panel: remaining time and finish clock | Remaining = estimate x (1 - file progress), corrected by how far elapsed time has drifted from plan. Show "done at 14:32" as well as "1 h 12 m left". | ready after J2 |
| J4 | Panel: model thumbnail | Slicer embeds a PNG thumbnail; Moonraker extracts it to `.thumbs/`. The panel fetches it over HTTP and decodes it with a vendored single-file decoder (lodepng or stb_image, static, no libs). Large one on the job screen, small one in the Print list. | ready |
| J5 | Panel: job screen | Thumbnail, name, progress bar, layer N / M, elapsed, remaining, finish clock, filament used (m and g), speed and flow %, temps with targets, fan. | ready after J3, J4 |
| J6 | Panel: tune during a job | Speed % (`M220`), flow % (`M221`), Z babystep (`SET_GCODE_OFFSET Z_ADJUST`, keep with `NOZZLE_OFFSET`), fan, temps, pressure advance. Big +/- buttons, the changed value highlighted. | ready |
| J7 | Panel: cancel one object | List from `exclude_object` (needs "label objects" in the slicer); tap one, confirm, `EXCLUDE_OBJECT NAME=`. Draw the bed with the objects' outlines so you pick the right one. | ready after J1 |
| J8 | Panel: end of job | Finished screen with real time vs estimate, filament used, cost (from the FreeCAD MaterialCost rates), buzzer cue; "Print again" button. | idea |
| J9 | Live layer preview | Panel draws the current layer's toolpath from the G-code as it prints (outline, nozzle position). Needs a cheap way to read the layer from the file without loading it into the SoC's RAM. | idea, stretch |

## 3. Slicer

Need: Klipper and Moonraker upload, thumbnails, object labels, by-object
sequence, single-extruder multi-material, colour painting, per-object and
height-range modifiers, calibration tools, editable profiles kept in git.

| Slicer | For | Against |
|---|---|---|
| **OrcaSlicer** | All of the above; the best calibration suite (PA, flow, temperature, retraction, max volumetric speed, VFA); first-class Klipper support; very active. | Another install. Check it has a CC2 profile so both printers stay on one slicer. |
| ElegooSlicer (now) | Already set up on the ASRock for the AD4 and the CC2; it is an Orca fork, so most features match. | Lags Orca; Elegoo-first defaults; one more fork between us and fixes. |
| PrusaSlicer | Solid, good multi-material and sequential. | Fewer calibration tools, weaker Klipper extras. |
| Bambu Studio, Cura | | Klipper support and profile control are weaker. |

Decision (S1, 2026-11-03): OrcaSlicer for the AD4 and the CC2.

| ID | Item | Approach | Status |
|---|---|---|---|
| S1 | Decide | Done 2026-11-03: OrcaSlicer 2.4.2 and ElegooSlicer 1.5.3.5 sliced the same two-object plate with the same AD4 presets to identical G-code (22m 24s, 100 layers, 1148 mm, `M73`, `EXCLUDE_OBJECT_DEFINE`); Moonraker reads slicer, time, layers and filament from both. Findings: the current ElegooSlicer process presets have label objects and `exclude_object` off (J7 needs them on); CLI slicing writes no thumbnails, only the GUI does. Both ship CC2 and AD4 profiles. **Caleb picked OrcaSlicer for both printers**; ElegooSlicer stays installed until Orca has sent a job to the CC2 with Caleb at it. | done |
| S2 | AD4 profile bundle in git | `improvements/slicer/`: OrcaSlicer printer, filament and process profiles, with `PRINT_START BED= EXTRUDER=`, labels on, thumbnails 32x32 and 160x160 PNG, `M73`, Klipper flavour, klipper_estimator post-process, 60 mm/s cap. Then send one job from Orca to the CC2 (Caleb at it). | ready |
| S3 | Calibrate | PA, flow, temperature towers per filament with the slicer's tools; results into the filament profiles and `printer.cfg`. Input shaper by ringing tower (no accelerometer). | after S2 |
| S4 | FreeCAD Slicer workbench | Caleb's own workbench already slices for the AD4; make it use the same profiles and send to Moonraker. Tracked in its own entry. | idea |

## 6. Speed and quality

| ID | Item | Approach | Status |
|---|---|---|---|
| Q1 | Pressure advance | Per filament, from S3. The ladder test already tried 0.05 and 0.5. | ready |
| Q2 | Input shaper | Ringing tower, read the frequencies by eye, `[input_shaper]`. Lets accelerations go up without ringing. | ready |
| Q3 | Max flow | The slicer's max volumetric speed test per filament; the hot end slips near 4.8 mm³/s with PLA. Above that, speed only buys you skipped extrusion. | ready |
| Q4 | Lift the 60 mm/s cap | Only if Q1-Q3 show headroom, and only on Caleb's decision. | blocked on Caleb |
| Q5 | Bed levelling | `[bed_mesh]` is in the config but there is no probe. Find out what the stock firmware used for levelling (sensor, pins) before buying anything. | idea |
| Q6 | Filament runout | The stock firmware reads PB7 (input, pull-down) every tick and flags it after 5000 ticks low: probably the runout switch. `[filament_switch_sensor]` on PB7 calling M1's swap flow. Verify with Caleb pulling filament. | ready |
| Q7 | Chamber by material | Chamber fan (PB9) on for PLA (heat creep), off or low for ABS/ASA, from `PRINT_START MATERIAL=`. | idea |
